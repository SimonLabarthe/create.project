# create.project

two functions to start any project, on any computer.

```r
create_project(path, type = "research")   # data pipeline + renv + paper in 5_docs/
create_project(path, type = "package")    # R package + paper in paper/
create_paper(dir)                         # just the LaTeX paper, in any project
```

## install

```r
remotes::install_github("SimonLabarthe/create.project")
```

## once per computer

keep renv package libraries out of OneDrive: run `usethis::edit_r_environ()`, add this line, restart R.

```
RENV_PATHS_LIBRARY_ROOT=C:/Users/<you>/AppData/Local/renv/library
```

## what you get

| research | package |
|---|---|
| `1_raw_data/` never edited by hand | `R/` all functions (starts with an example `hello()`) |
| `2_scripts/` numbered = execution order | `man/` generated by `devtools::document()` |
| `3_derived_data/` regenerated by the scripts | `tests/testthat/` unit tests |
| `4_outputs/figures/`, `tables/` | `vignettes/` tutorial |
| `5_docs/main.tex` the paper | `data-raw/` scripts that build `data/` |
| `6_archives/` old stuff | `inst/CITATION` (built from DESCRIPTION) |
| `renv/` pinned package versions | `paper/main.tex` (build-ignored) |

both: `DESCRIPTION`, `NAMESPACE`, `.Rproj`, `LICENSE`, `README.md`, `.gitignore`, `.Rbuildignore`, first git commit on `main`.
`publish_github = TRUE` also creates a private GitHub repo and pushes.

## edit the paper template

`inst/templates/paper.tex` is plain LaTeX: `{{name}}` is filled by `create_paper()`, `[...]` is writing guidance.
after editing, reinstall (`devtools::install()`).

## this repo
