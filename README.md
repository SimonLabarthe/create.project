# create.project

a whole research project (folders, renv, git, a paper with APA references and an automatic word count) in one line.

## 1. start a project: one line

open RStudio, paste this in the **console** (bottom-left), change the path, press Enter:

``` r
install.packages("remotes"); remotes::install_github("SimonLabarthe/create.project"); create.project::create_project("C:/Users/<you>/OneDrive/university/26b/seminar/my_paper")
```

that's it: no file to save, no `library()`. then open `my_paper/my_paper.Rproj`.

- the last folder of the path (`my_paper`) becomes the project name; the folder is created if needed.
- run the same line again for every new project: `install_github()` skips the download when nothing changed on GitHub, and picks up the latest version when something did.
- first time on a computer: it also tells renv to keep package libraries out of OneDrive (it adds `RENV_PATHS_LIBRARY_ROOT` to your `~/.Renviron`). nothing to do by hand.

## 2. what you get

```
my_paper/
├── 1_raw_data/          never edited by hand
├── 2_scripts/           01_extract ... 05_figures: numbered = execution order
├── 3_derived_data/      regenerated by the scripts
├── 4_outputs/figures/   + tables/
├── 5_docs/
│   ├── main.qmd         the paper
│   ├── references.bib   export from Zotero (Better BibTeX)
│   ├── apa.csl          APA 7th reference style
│   ├── header.tex       the LaTeX look
│   └── _extensions/     word count
├── 6_archives/          old stuff
├── renv/                pinned package versions
└── my_paper.Rproj, DESCRIPTION, LICENSE, README.md, .gitignore, first git commit on main
```

## 3. write the paper

open `5_docs/main.qmd`, write, click **Render**. you get `main.pdf` with:

- references in **APA** (`apa.csl`), from `references.bib`: cite with `@author2020`
- the **word count** under the title, updated at every render (body only: no abstract, notes, references)
- tables and numbers computed by R at render time: never stale

the example tables need `install.packages(c("dplyr", "modelsummary"))` once. everything in `[...]` is writing guidance to replace; `\todo{...}` prints in red, search "todo" before submitting. example figures (`example_*.pdf`, from `dplyr::starwars`) are there so nothing starts blank: replace them with yours.

## 4. options

``` r
create.project::create_project(path,
  title          = "Why does X affect Y?",   # printed on the paper
  type           = "package",                # R package instead of a research project (paper in paper/)
  format         = "latex",                  # main.tex instead of main.qmd (no automatic word count)
  publish_github = TRUE                      # also creates a private GitHub repo and pushes
)
```

- other reference style: `create_paper(bib_style = "chicago-author-date")` (any name from <https://www.zotero.org/styles>).
- `publish_github = TRUE` needs a GitHub token once: `usethis::create_github_token()`.
- LaTeX papers: compile with `create.project::compile_paper("5_docs")`, **not** RStudio's "Compile PDF" button (it runs BibTeX; the templates use Biber, so references would stay empty).

## 5. just a paper, in a project you already have

``` r
create.project::create_paper("5_docs")                                       # research paper
create.project::create_paper("paper", type = "software", package = "coolfun") # paper about an R package
```

existing files are never overwritten.

## 6. Quarto or LaTeX

|   | Quarto `main.qmd` (default) | LaTeX `main.tex` |
|----|----|----|
| you write | Markdown (+ LaTeX when needed) | LaTeX |
| references | `apa.csl` | biblatex `apa` |
| word count | automatic, under the title | by hand |
| tables, numbers in the text | computed by R at render: never stale | written by your scripts, or copied by hand |
| to PDF | Render button | `compile_paper("5_docs")` |
| look | `header.tex`: same as the LaTeX paper | `preamble.tex` |

## 7. editing the templates (this repo)

`{{name}}` is filled by `create_paper()`, `[...]` is writing guidance. after editing: `devtools::document()`, `devtools::test()`, push. the one line in section 1 then installs the new version.

| file | role |
|----|----|
| `R/create_project.R` | `create_project()` and its layout helpers |
| `R/create_paper.R` | `create_paper()`, `compile_paper()` |
| `inst/templates/paper/quarto/` | `research.qmd`, `software.qmd`, `header.tex` (LaTeX look), `apa.csl` (CC BY-SA, CSL project), `_extensions/` (word count, MIT, by Andrew Heiss) |
| `inst/templates/paper/preamble.tex` | LaTeX packages and title block, shared by both LaTeX papers |
| `inst/templates/paper/research.tex`, `software.tex` | LaTeX bodies |
| `inst/templates/paper/figures/` | example figures copied into new papers |
| `data-raw/example_figures.R` | makes those figures (build-ignored) |
| `inst/templates/project.Rproj` | RStudio settings copied into new projects |
| `paper/` | the paper introducing this package (build-ignored) |
| `tests/testthat/` | tests, `devtools::test()` |
| `DESCRIPTION`, `LICENSE` | package metadata |
| `NAMESPACE`, `man/` | generated by `devtools::document()`: never edit |
